# Haunt

A full-screen terminal home for programmable widgets. An Anomaly project.

Create widgets by prompting, arrange them on a stable drag-and-resize grid, and
switch between saved dashboards. Widgets use plain Lua, OpenTUI primitives, and
explicit UI updates, with general-purpose filesystem, API, and process access.

Status: design baseline. The first milestone is a native Zig/OpenTUI/Lua integration
prototype.
